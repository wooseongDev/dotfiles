# AGENTS.md

## 대화와 표기

- 대화는 항상 한국어로 한다.
- 기본적으로 ELI5 방식으로 설명한다. 사용자가 더 자세히 물으면 원리와 세부 내용까지 설명한다.
- 코드, 명령어, 식별자, 인용문은 원래 표기를 유지한다.
- 범위를 나타내는 `~` 앞뒤에 공백을 넣는다.
- 일반 문장에서는 가운뎃점(`·`) 대신 쉼표를 쓴다.
- 일반 문장에서는 em dash(`—`) 대신 마침표, 쉼표, 콜론, 괄호 중 문맥에 맞는 것을 쓴다.

## pstack 사용

Codex에서 pstack 스킬을 호출하면 `~/.cursor/rules/pstack-models.mdc`를 읽는다.
스킬의 Cursor 기본값보다 파일의 역할별 모델 설정과 실행 지침을 우선 적용한다.
